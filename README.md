# Развертывание MediaWiki в Яндекс Облаке

## Описание проекта
Данный проект представляет собой инфраструктурный код для развертывания отказоустойчивой инсталляции MediaWiki в Яндекс Облаке с использованием Terraform. Инфраструктура включает в себя балансировщик нагрузки, два frontend-сервера, PostgreSQL в режиме master-replica и комплексную систему мониторинга.

- Зона доступности: ru-central1-a

## Использование

### Предварительные требования
- Terraform 1.11.4 или выше
- Доступ к Яндекс Облаку
- Настроенный SSH ключ

### Параметры подключения
```hcl
cloud_id  = "b1ga2002v15rfm29hnku"
folder_id = "b1gtnji4taus00p96dsu"
zone      = "ru-central1-a"
```

### Развертывание
1. Клонировать репозиторий
2. Настроить переменные в terraform.tfvars
3. Инициализировать Terraform:
   ```bash
   terraform init
   ```
4. Применить конфигурацию:
   ```bash
   terraform apply
   ```

### Проверка работоспособности
В проекте есть два скрипта для проверки сервисов:
- check_services.sh (для Linux/Unix систем)
- check_services.ps1 (для Windows)

Скрипты проверяют:
- Доступность MediaWiki
- Работоспособность PostgreSQL
- Доступность систем мониторинга
